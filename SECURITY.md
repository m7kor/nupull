# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Nupull, please do **NOT** open a public issue.
Instead, report it responsibly via GitHub Security Advisories or privately to the maintainers.

## Proprietary Keys & Copyright Policy

Nupull is an independent open-source container, archiver, and modding utility.
- **NEVER** share or commit Nintendo proprietary cryptographic keys (`prod.keys`, `title.keys`, master keys) in issues, PRs, or commits.
- **NEVER** upload, attach, or link to copyrighted commercial Nintendo Switch ROMs, game dumps, or pirated software.
- Violations of this policy will result in immediate sanitization, closure, and potential repository restrictions.
